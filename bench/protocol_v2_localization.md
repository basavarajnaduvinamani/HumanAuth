# Classical card localisation protocol

Declared locally 2026-11-03 before any public-capture localisation scores. Not publicly preregistered. Seed 20261103. No learned detector or training.

Source: original authors' `ftp://smartengines.com/midv-2020/dataset/photo.tar`; licence `ftp://smartengines.com/midv-2020/license.txt`, CC BY-SA 2.5. Mock documents have generated portraits, not real personal identity records. Images stay ignored. Record annotation/member SHA256, names, dimensions, selection IDs SHA256 and the publisher's archive MD5. Do not claim the complete archive hash was verified if only member ranges were retrieved. The university HTTPS mirror has an expired certificate; do not disable TLS validation to use it. The authors explicitly publish the FTP source.

Read all ten original VIA annotations. Retrieve the first ten photo members in stored tar order for each of the ten templates (100 captures). This is a deterministic bounded engineering diagnostic, not a random population sample or full benchmark. Selection precedes scoring and does not depend on conditions or success. Record capture condition counts from the authors' numeric filename convention. A tar header checksum, exact byte count, annotated original file size and decoded dimensions must validate before use. Retain every selected failure; do not replace it with an easier capture.

Candidate: browser TypeScript Otsu segmentation in both polarities, connected components, convex hull reduction to four vertices, explicit area/fill/border/ambiguity checks; perspective correction by homography and bilinear sampling. Settings fixed in `web/src/lib/document-localization.ts` before scores. Candidate is initially not wired into the product. Algorithm unit tests use synthetic rectangles and coordinate ramps, not benchmark photos. No parameter tuning on these 100 captures; any revision gets a separately labelled follow-up rather than overwriting the first result.

Compare predicted polygon with the official `doc_quad` polygon. Use polygon intersection/union with the annotated polygon clipped to image bounds; retain out-of-frame annotations and report their count. Missing/ambiguous detection scores zero IoU and is a localisation failure. Report detection coverage, mean/median IoU over all captures, proportion IoU >=0.5 and >=0.8, and the same values by source template/condition. Bootstrap 2000 replicates, seed 20261103, resampling templates then captures within each sampled template; percentile 95% CIs. This reflects the bounded template/capture sample, not all document designs or camera users.

Save aggregate JSON + Markdown under `bench/results/`. Raw photos, intermediate pixels, source annotations and per-image geometric output stay ignored. A successful quadrilateral is not an authenticity result. A poor result must remain visible, with a recapture/manual-review path and no silent success fallback. Validate perspective geometry independently; no real-device camera performance claim follows from public source photos.
